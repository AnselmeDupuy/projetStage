Application transformant des fichier d'incident TOML en un fichier html lisible et navigable, un graphique indiquant clairement les perte sur sur chaque incidents et la possibilité de voir les informations complète de chaque incidents.

Dépendence:
    - chart.js
    - beautifulSoup4
    - toml
    - Pillow
    - csscompressor
    - jsmin
    - htmlmin2
    - markdown
